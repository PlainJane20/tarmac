# TARMAC glossary

| Term | Definition |
| --- | --- |
| Accountable owner | Person or designated role with authority for a material decision or outcome. |
| Architecture | TARMAC pillar that resolves solution direction, constraints, reusable patterns, and control planning. |
| Automation & CI/CD | Cross-cutting capability for repeatable evidence, rules, orchestration, pipelines, and reconciliation. |
| Baseline | Approved reference point for scope, schedule, cost, risk, metric, or benefit comparison. |
| Compliance & Governance | Cross-cutting capability for policy, decision rights, risk, exceptions, retention, and audit. |
| Control plane | Layer coordinating policy and decisions across systems without replacing their native execution records. |
| Decision SLA | Working time from evidence-complete submission to accountable response. |
| Evidence | Cited fact with source, scope, version/time, freshness, and access classification. |
| Finding | Result of evaluating a rule or reviewer judgment against evidence. |
| Monitoring | TARMAC pillar connecting service health, operational learning, adoption, and benefits to the portfolio. |
| Release | TARMAC pillar that evaluates production readiness and records authorization or blocking rationale. |
| Triage | TARMAC pillar that turns demand or operational feedback into a portfolio decision. |
| Waiver | Time-bounded, scoped acceptance of risk with owner and compensating control; it does not erase a failed finding. |
