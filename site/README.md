# TARMAC GitHub Pages site

This directory contains the dependency-free Foundation v0.1.0 product experience. It presents the TARMAC story, interactive operating model, ITPMO modernization, architecture, transparent value model, metrics, and roadmap.

## Preview

Open `index.html` directly or serve the repository with any static file server and navigate to `/site/`.

## Publish

The repository's `pages.yml` workflow validates the project, stages this directory as the site root, adds the canonical brand social preview, and deploys through GitHub Pages. In repository settings, choose **Pages → Source → GitHub Actions**.

## Claim policy

All calculator outputs are labeled modeled scenarios. Capacity released, cost avoided, spend redirected, cost-of-delay reduction, risk reduction, realized benefits, and cashable savings remain distinct. See the [value method](../flight-deck/08-metrics-and-value.md).
