# TARMAC brand system

## Identity

TARMAC is the calm operating surface between enterprise strategy and software delivery. It should feel credible in an executive review, legible in an operations room, and precise in an architecture decision.

**Category:** The Enterprise Delivery Control Plane

**Promise:** From idea to impact. Governed by design.

**Product line:** Plan with precision. Launch with confidence.

**Proof:** Four delivery pillars. Two cross-cutting capabilities. One operating model.

## Mark

The primary mark is a capital **T** aligned by four approach lines. It is implemented with type and CSS in the application and site so it remains crisp, accessible, themeable, and dependency-free.

Use the mark beside the `TARMAC` wordmark. Preserve one-half mark width of clear space. Do not rotate it, add aircraft silhouettes, place gradients inside it, or use signal colors decoratively in ways that confuse status meaning.

## Typography

Use a modern system sans stack for product interfaces and narrative: Inter, Aptos, Segoe UI, Helvetica Neue, Arial, sans-serif. Use a system monospace for identifiers, formulas, timestamps, and measured values. The experience must not depend on a remote font.

## Layout and motion

Use alignment rails, fine borders, directional connectors, and controlled signal lights. Favor high information clarity over ornamental empty space. Motion communicates sequence or state change in 120–240ms and stops when reduced motion is requested.
