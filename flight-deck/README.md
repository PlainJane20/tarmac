# TARMAC Flight Deck

**Release:** Foundation v0.1.0 “Flight Ready”

**Status:** Early-stage reference implementation

**Purpose:** Versioned product, operating-model, architecture, and governance source of truth

The Flight Deck explains not only how TARMAC works, but why it exists, which decisions it supports, how value is measured, and which questions remain open. Application features and public claims should trace back to this blueprint.

## Governance

Material changes to the TARMAC acronym, operating model, product boundary, authoritative data, trust model, public metric definitions, or deployment architecture require an Architecture Decision Record (ADR). Roadmap and metric changes identify an owner, evidence, and review date. Modeled benefits are never presented as observed results.

The existing All Rights Reserved license remains in force until the owner explicitly resolves [Open Decision OD-001](11-open-decisions.md#od-001--ownership-and-license).
