# Security policy

TARMAC is a private portfolio project and is not operated as a production service. Do not open public issues containing credentials, personal information, or vulnerability details.

For a security concern, contact the repository owner privately through GitHub. Include the affected component, reproduction steps, potential impact, and any suggested mitigation.

## Reporting expectations

- Do not include secrets, tokens, or connection strings in reports.
- Allow reasonable time for investigation before public disclosure.
- Do not attempt to access data or systems you do not own.
